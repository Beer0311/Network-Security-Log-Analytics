# Network Security Log Analytics
# Network Threat Intelligence Pipeline

## Project Overview
An end-to-end analytics pipeline designed for a 3rd-year B.Tech CSE case study.This project processes 40,000+ raw network logs to identify security vulnerabilities.

## Engineering Highlights
ETL Pipeline:Transforms unstructured firewall logs into structured DataFrames using Python.
Threat Scoring: Implements custom logic to prioritize critical alerts based on packet size and severity.
Temporal Analysis: Visualizes peak attack windows to identify automated botnet activity.
